# figures_manifest — 검토 화면 빌드용(디자이너)

그림 세 장이고, 각각 결함을 하나씩 일부러 심은 초안(`v1`)이다. 데이터와
생성 코드는 `run_manifest.md`를 본다.

검토 화면은 아래 **v1 초안** 파일을 검토할 재료로 불러온다. 무엇이 결함인지는
화면에서도 이 문서에서도 미리 알려 주지 않는다("이게 왜 고쳐야 하지" 하는
순간을 스포일링하지 않는다). 결함 정체와 수정 참조본은 `loop-history/`에 있다.
반영을 마친 뒤 비교할 때 연다.

| 초안(화면에 올릴 것) | 그림 종류 |
|---|---|
| `figures/fig1_bar_v1.png` | 막대그래프(지역별 손실지수) |
| `figures/fig2_grid_v1.png` | 히트맵 + 컬러바(합성 격자) |
| `figures/fig3_scenarios_v1.png` | 히트맵 두 패널(시나리오 A·B) |
