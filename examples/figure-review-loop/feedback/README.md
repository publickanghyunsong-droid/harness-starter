# feedback/

이 폴더는 `dashboard.html`에서 "반영 요청 (md 내보내기)"를 누르면 받는 파일을 넣는 자리다.

- 지금은 비어 있다. `dashboard.html`을 열고 그림에 피드백을 남긴 뒤 내보내면
  `<대시보드-id>-feedback-<시각>.md` 형식의 파일이 다운로드된다. 그 파일을
  여기에 옮겨두면 다음 리뷰 라운드의 입력이 된다.
- 실제로 있었던 1차 라운드의 피드백 원문은 여기가 아니라
  `../loop-history/feedback/`에 보관돼 있다 — 그건 "이미 반영된" 과거 기록이고,
  이 폴더는 "아직 반영 안 된" 새 피드백을 받는 곳이라 구분했다.
